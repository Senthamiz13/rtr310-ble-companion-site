IPHONE · PERSONAL DEVELOPMENT INSTALL

Install with Xcode
on your own iPhone.

A Mac, Xcode, and a free Apple Account are enough to build RTR Link and run it on your personal iPhone. This is a development install that you perform from Xcode; it is not an iOS download link that anyone can install from the website.

What this means: you can try the app on your own device without TestFlight or a paid Apple Developer Program membership. The free Personal Team signing is temporary and intended for personal development and testing. Public iPhone distribution through TestFlight or the App Store requires Apple Developer Program membership.

Before you start

  • A Mac that can run a current version of Xcode.
  • A free Apple Account added in Xcode under Xcode → Settings → Accounts.
  • Your iPhone, a USB cable, and the device passcode.
  • An iPhone running iOS 16 or later. RTR Link currently targets iOS 16+.

1. Get the project

In Terminal, clone the public source repository:

git clone https://github.com/Senthamiz13/rtr310-ble-companion.git
cd rtr310-ble-companion
open ios/TVSBike.xcodeproj

2. Set up signing in Xcode

  1. In Xcode’s project navigator, select the TVSBike project, then select the TVSBike app target.
  2. Open Signing & Capabilities and enable Automatically manage signing.
  3. Choose your Apple Account’s Personal Team in the Team menu.
  4. If Xcode reports that the bundle identifier is already in use, change it to a unique identifier, such as com.yourname.RTRLink.

3. Run it on iPhone

  1. Connect and unlock your iPhone. If prompted, trust this Mac on the phone.
  2. Select your iPhone as the run destination in Xcode’s toolbar.
  3. Press the Run button (▶) and wait for Xcode to build and install the app.
  4. If iPhone asks for Developer Mode, go to Settings → Privacy & Security → Developer Mode, turn it on, restart, then confirm.
  5. Open RTR Link and allow Bluetooth access when prompted.

Keep the install working

With a free Personal Team, the development provisioning profile expires after 7 days. When the app stops opening, connect the phone to the Mac and run the app again from Xcode to refresh the signing and install it again.

Apple currently limits a Personal Team to 10 App IDs and 3 registered devices, with the relevant registrations expiring after 7 days. These limits can change; see Apple’s account documentation.

Want to share it with other iPhone users?

This Xcode route is for installing your own development build. It does not create a public website download. Wider distribution via TestFlight or the App Store requires joining Apple’s Developer Program (currently USD $99 per year; local pricing may vary). There is no RTR Link TestFlight build available at this time.

Android users can install the Android 0.1.0 APK from the downloads section.
